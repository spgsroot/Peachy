# Page pipeline baseline

Date: 2026-11-15. Code: `931e313`, immediately after Task 1; no Phase 1 changes. Phone: A069P, Android 17, arm64-v8a, serial `00324362A000776`. Separate `.eval` app; original app untouched.

## Method

Three fresh instrumentation runs per configuration; selected the median run by summed per-page stage time. 14 Japanese pages (`ja`), 16 English pages (`en`), all 30 (`auto`). Local files, same JPEG encoding as production PageBytes.jpeg, then OCR and original-text plate layout at fitted 1080 × 1920. Stages use integer ms; p50/p95 use nearest rank. Heap is maximum Java-used + native-allocated MB sampled after stages, not a continuous high-water measurement. Phone awake; battery saver off; initial battery 27°C, 15-second pause between runs. Raw JSON stays outside the repository under Desktop/manga-tests/eval-results. No provider or network request ran.
