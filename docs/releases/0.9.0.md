# Peachy Android 0.9.0

## Русский

**Переход с 3.7.1:** скачайте `app-release-unsigned-signed.apk` из файлов релиза и установите поверх текущей версии. Не удаляйте Peachy. Старый обновлятор не предложит меньший номер версии, но Android распознает обновление по `versionCode 15` (было 14).

- **Манга → Для вас:** кнопка «Прочитано» слева от «Не интересно» убирает галерею из выдачи, добавляет её в историю и учитывает как полностью прочитанную при следующем обновлении подборки.
- «Не интересно» понижает галереи с похожими тегами, даже если в истории ещё нет положительных отметок. Это не блокирует теги.

## English

**Updating from 3.7.1:** download `app-release-unsigned-signed.apk` from the release assets and install it over the existing app. Do not uninstall Peachy. The old updater will not offer a lower version name, but Android recognizes the higher version code (15, up from 14).

- **Manga → For you:** **Already read**, to the left of **Not interested**, removes the gallery from your picks, adds it to your reading history and counts it as a completed read on the next refresh.
- **Not interested** ranks galleries with similar tags lower even before you have recorded any likes. It does not block those tags.
