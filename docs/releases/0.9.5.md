# Peachy Android 0.9.5

## Русский

- Сортировка очереди вернулась в верхнюю панель плеера. Если места не хватает, «Документы» и «Браузер» открываются через «Ещё»; сортировка остаётся на месте.
- При переводе страницы модель получает реплики как единый диалог. В режиме «Вся галерея» тот же провайдер может получить до шести переведённых реплик с предыдущей страницы. При нажатии на отдельную реплику соседние страницы не отправляются.
- Неполный ответ на распознанный текст больше не сохраняется как перевод всей страницы. Для уже сохранённой страницы выберите «Перевести снова».
- В карточке манги отметка «Прочитано» не меняет позицию чтения. Управление связями открывается в разделе «Переводы и главы».

## English

- Queue sorting is back in the player toolbar. When space is tight, Documents and Browser move into More; sorting stays visible.
- Pages are translated as dialogue. In Whole gallery mode, the same provider can receive up to six translated lines from the previous page. A single-bubble request never includes an adjacent page.
- Incomplete OCR replies are no longer saved as finished pages. Use Translate again to replace a previously saved translation.
- The read mark on gallery details does not move your bookmark. Expand Translations & chapters to manage links.
