# Peachy Android 0.9.2

## Русский

Для перехода с первой сборки 0.9.2 (код 17) на эту (код 18) установите подписанный APK поверх приложения, не удаляя его. Встроенная проверка сравнивает названия версий и не предложит обновление с тем же номером 0.9.2.

- «Документы» и «Браузер» открываются прямо из панели плеера; «Библиотека» появляется там после включения NSFW. На ширине 320 dp кнопки остаются в одном ряду, сортировка и фильтры очереди — под панелью.
- В галерее поле поиска переходит на отдельную строку, если подсказка не помещается в панели. Сообщение пустой галереи выровнено по центру.
- В «Документах» можно сортировать файлы по дате, имени или размеру и задавать диапазон размеров.
- Манга, перевод, управление устройствами и захват звука в браузере по умолчанию выключены, в том числе после обновления. Переключатель в настройках не удаляет сохранённые материалы. В релизной сборке по-прежнему заблокированы снимки экрана.
- После разблокировки восстанавливается открытый раздел или вкладка браузера. «Назад» сначала проходит по истории страницы, затем возвращает на предыдущую вкладку.
- Из карточки манги можно скопировать полное название. Перевод размещается внутри распознанного светлого бабла или рамки текста и заново переносится при увеличении. Если плашка не вмещается, сохранённую реплику можно прочитать в панели.
- У текстовых OCR-запросов снято клиентское ограничение в 4096 токенов. Если провайдер обрывает ответ, читалка отличает исчерпанный лимит вывода от отказа и не посылает страницу повторно при таймауте.

## English

To move from the first 0.9.2 build (code 17) to this build (code 18), install the signed APK over the existing app. Do not uninstall it. The built-in update check compares version names and will not offer another 0.9.2 build.

- Open Documents and Browser directly from the Player toolbar. Enabling NSFW features adds Library to the same row. At 320 dp wide, the buttons fit on one row with queue sorting and filtering below.
- Gallery moves the search field to its own row when the hint won’t fit in the toolbar. The empty-library message is centered.
- In Documents, sort files by date, name, or size, and filter by a size range.
- Manga, translation, device control, and browser audio capture are off by default, including after upgrading. Switching them off keeps saved items. Release builds still block screenshots.
- Unlocking restores the previous screen or browser tab. Browser Back follows page history before returning to the previous tab.
- Copy the full title from manga details. Translation plates fit inside detected light balloons or source text bounds and rewrap on zoom. When a plate cannot fit, the saved line is still available in the panel.
- OCR text requests no longer impose a 4096-token cap. The reader distinguishes unusable output truncated at the provider limit from a refusal, and does not resend a timed-out page.
