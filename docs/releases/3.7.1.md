# Peachy Android 3.7.1

## Русский

- Жест Android «Назад» возвращает на предыдущую страницу. В начале истории он переключает на вкладку, из которой вы пришли, не закрывая ни одну из них. Если возвращаться некуда, браузер закрывается.
- Кнопки «Назад» и «Вперёд» учитывают переходы внутри страницы, в том числе когда сайт меняет адрес без перезагрузки.
- При пересоздании браузера ссылка, открытая из приложения, больше не открывается во второй вкладке.

## English

- Android Back returns to the previous page. At the start of a tab’s history it returns to the tab you came from, leaving both tabs open. If there is nowhere to go back to, it exits the browser.
- Back and Forward follow in-page history, including sites that change the address without reloading.
- Recreating the browser activity no longer opens the original launch link in a second tab.
