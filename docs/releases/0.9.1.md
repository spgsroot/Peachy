# Peachy Android 0.9.1

## Русский

- В читалке откройте **Настройки → Перевод → По нажатию на текст**. Нажмите на реплику, чтобы перевести только её на выбранный язык. ML Kit передаёт провайдеру распознанный текст, а визуальная модель — фрагмент изображения вместо всей страницы.
- Перевод больше не закрывает рисунок вокруг реплики. Если текст сокращён, повторное нажатие откроет его целиком без нового запроса. Если не помещается даже одна строка, панель откроется сразу.

## English

- In reader settings, choose **Translation → Tap bubble text** to translate just the bubble you tap into the selected language. ML Kit sends the recognized text; vision mode sends a crop instead of the entire page.
- On-page translations stay within the original text bounds. Tap a shortened translation again to read it in full without another request. If not even one line fits, the full text opens in the panel immediately.
