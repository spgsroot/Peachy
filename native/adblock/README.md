# Browser shield

Build Android with the project Gradle wrapper, Python 3, the Android NDK **28.2.13676358** and Rust **1.99.1** (host std plus `aarch64-linux-android`, `armv7-linux-androideabi`, `i686-linux-android`, `x86_64-linux-android`). Set `ANDROID_NDK_HOME` and put `rustc` and `cargo` on PATH. Windows Gradle also supports the existing WSL Debian toolchain, with NDK in `~/Android/ndk/28.2.13676358` and Rust on PATH or in `~/.local/share/peachy-adblock/toolchain-1.99.1/usr/bin`. No install step runs during the build. Cargo fetches only dependencies in `Cargo.lock`; an offline build requires them in the Cargo cache.

`:app:assembleDebug :app:assembleRelease` compiles the Peachy JNI library for all four ABIs and checks each APK with `tools/adblock/verify-apk.py`. Missing ABIs, a mismatched ELF machine or a misaligned 64-bit native library fail the build. There is no native-loader fallback or copied `.so`. `zipalign -c -P 16 4` provides an independent ZIP check; a 4 KiB device run is not a 16 KiB runtime test. `cargo test --locked --manifest-path native/adblock/Cargo.toml` exercises the rules and host fast path. `-Ppeachy.browserQa=true :app:assembleDebug :app:assembleDebugAndroidTest` builds the separate `ru.spgsroot.peachy.browserqa` application/runner (launcher label: **Peachy Browser QA**); never install the regular package for browser QA.

## Behaviour against pinned Orbit

Reference: [Orbit `c2b6077`](https://github.com/egeeuzun/orbit/tree/c2b6077f0c309b2a8fa830a7a8c8e19e4cf4259a). Comparison below concerns application wiring, not library marketing. No Orbit source, script, starter list or binary is used.

| Area | Orbit source at pin | Peachy |
|---|---|---|
| Request decisions | URL, main page as source, inferred type, method; regular and important filters and exceptions. The redirect **bit** is returned but its payload is not served. | Uses `BlockerResult::should_block` and built-in local replacement bodies when available. Unknown replacement on a blocked request is an empty block, never a network redirect. No main-document rewriting, CSP rewriting, response-body filtering or URL-parameter replay. |
| Host path and cache | Host blocks precede normal exceptions; decisions cached. | A positive domain hit skips regular block lookup, **not** exceptions, priorities or redirects. Disabled host rules are excluded. 512-entry process-only LRU includes URL, source, kind and method; replaced generations and clear-data invalidate it. |
| Lists | 30 named subscriptions (12 defaults), per-list selection, local rules, custom URLs, bounded includes, update at browser startup when three days old. No named presets in Settings. | Same catalogue and extra Peachy Adult list; the existing three lists remain the offline baseline. Initial and three-day refresh after unlock, manual update, local edits, includes, staged files and one active-generation pointer. No visited page data or browser cookies sent to publishers. Custom text and subscription URLs/bodies encrypted at rest; private engines rebuilt in memory, not serialized to disk. |
| Cosmetics | Document-start runtime; page CSS, generic class/ID selectors and procedural rules. Kotlin exposes native resources and a script string but does not call the loader or run that string. | Origin-scoped document-start injection for prepared top-level HTTPS destinations. CSS, dynamic generic selectors with exceptions, procedural actions and packaged uBlock scriptlets. Remote subscriptions **cannot** supply scriptlet implementations or acquire privileged scriptlet permissions. On a provider missing document-start support the page is filtered after commit; without web messaging dynamic generic lookup is unavailable. |
| Controls | Global/network, cosmetic and generic switches; site allowlist, page and lifetime counts. | Settings within existing Compose menu; site exceptions remain in the encrypted browser store. Counters have no hostname/URL history. Clearing site data closes tabs and clears in-memory request decisions; subscriptions and aggregate statistics are app settings, not web storage. |

WebView does not expose the requesting frame's full initiator or resource type; the main-page source and `Sec-Fetch-Dest`/header/extension inference are approximations. WebView does not intercept every protocol, WebSocket frame, renderer-cached load, redirect hop or service-worker request. Unexpected committed destinations may get cosmetic rules after commit. The ad blocker does not relax HTTPS, external-navigation consent, deny-by-default WebView permissions or gesture/approval requirements for new windows. `$popup` is not an independent `RequestType` in Brave 0.13.5; popup probes can match ordinary URL rules, not reliably `$popup`-only rules.

## Third-party inputs

See [SOURCES.txt](../../app/src/main/assets/adblock/SOURCES.txt). `tools/adblock/prepare-resources.mjs` reproduces the scriptlet payload from an immutable uBlock revision; run it with Node's `--experimental-vm-modules` only when updating the reviewed bundle. `tools/adblock/collect-notices.py` regenerates the notice archive with the same Cargo/Rust environment used by the native build. Orbit's README declares MPL-2.0, but the covered files and provenance of its assets and `.so` were not established. Peter Lowe's subscription is fetched directly from its publisher, not bundled or mirrored; redistribution rights were not verified.
